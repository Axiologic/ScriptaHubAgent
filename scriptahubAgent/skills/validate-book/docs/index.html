ValidateBook layout and structure

Deterministic local PDF/HTML structure, font and display checks. The bundled Node.js implementation corrects English presentation, propagates it to existing languages, and checks each translated document without rewriting its prose. Book verification and correction use no LLM, model API, Python command or external review plan. Reports contain text only.

Unmapped English typography blocks completion regardless of text overlap. Tables require source cell text/span matches and checks of fills, borders, column proportions, vertical alignment and rendered fonts. Source evidence supports closed grids and columns established by cell fills and horizontal rules. Paginated typography scales with page width above the physical-size floor, preserving readable reflow on small screens. Standalone and imported delivery are checked after normalization by their page widths; unsupported or ambiguous tables remain errors.
