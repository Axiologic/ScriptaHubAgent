# Package 3.2.0

Makes workspace integration optional. Credential files now require `--credentials-file PATH` or an explicitly selected workspace root; parent-directory and skill-local secret discovery are removed. Public settings, output and cache defaults belong to the current working directory. Use `--settings`, `--out` and `--cache` to retain an existing location. Optional `setup` accepts a settings destination. The source and package versions now agree.

The Node suite adds copied-folder and configuration-precedence tests. No Python migration, model installation or provider API change is included. Existing scores and player bundles retain their formats. Version-aware caches may require new synthesis; keep accepted rendered bundles and choose request budgets deliberately.

# Package 3.0.0

Adds ten native cloud adapters, a dated 13-provider offer registry, nine recurring-free profiles, a no-network plan command, source-character/request pacing guards, explicit cast validation for new engines, and browser-only no-key audition. Adds configuration and contract tests; retains existing timeline, local models and original three cloud engines.

Score format remains theatrical-audio/1, with additive provider-specific fields. Existing source scores remain valid. Recasting is required when changing engines; voice identity is not portable between models. The version/source-aware cache intentionally may not reuse old-release synthesis keys. Do not assume an upgrade costs zero API requests: use plan and a low request cap. Keep old rendered bundles for free offline playback.

Install in a new directory, copy selected public settings and set credentials locally. Do not publish your old .env/cache. Private Python virtual environments are path-dependent: avoid moving an installed venv; perform setup again in its final location when needed. The ZIP contains code and documentation, not neural weights or API keys.
