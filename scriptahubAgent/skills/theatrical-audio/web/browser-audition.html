Browser voice audition

No API key, installation or server is needed for this page. Available voices come from your browser or operating system.

Listening only — not a file-export backend. Web Speech synthesis does not provide a standard WAV download. Its event timing and emotional control are not suitable as the authoritative animation timeline. Use the CLI to generate production clips.

“Local” reflects the browser's localService flag, not an independently audited privacy guarantee. A “remote” voice can send the text to its provider when you press Speak. No API keys are collected or stored.

Rate and pitch are not emotion knobs. There is no guaranteed whisper, anger, character identity across devices, or neural-quality voice. No cloud website is scraped and no undocumented browser service is accessed by this page.
