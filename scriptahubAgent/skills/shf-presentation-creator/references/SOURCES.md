# External implementation references

Consulted 2026-09-10. These sources support the standards/interchange and rights distinctions; the SHF design, editorial defaults, library drawings and original procedural scores are local design work, not externally validated effectiveness claims.

- Agent Skills, specification: https://agentskills.io/specification — portable skill directory and SKILL.md metadata convention. Host discovery and installation paths still vary.
- W3C, Web Audio API, Recommendation 17 June 2021: https://www.w3.org/TR/2021/REC-webaudio-20210617/ — audio contexts, buffer scheduling and gain-node graph. The implementation uses those browser mechanisms; this source does not certify our player.
- W3C, Web Audio API 1.1 Working Draft: https://www.w3.org/TR/webaudio/ — work in progress, not used as a claim of final standard status.
- Musopen FAQ: https://musopen.org/faq/ — starting point for checking exact music resources and usage conditions; not a blanket license for arbitrary classical recordings.
- US Copyright Office, Circular 56A: https://www.copyright.gov/circs/circ56a.pdf — composition and sound recording are distinct works for US copyright purposes. This is not a determination of worldwide public-domain status or synchronization rights for a specific asset.

No externally sourced font files, stock illustration library or classical recordings are bundled. The classical shortlist is an editorial selection aid; its entries are not pre-cleared media assets.
